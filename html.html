HTML Basics

Learn the building blocks of every webpage.

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of websites.


Think of HTML as the skeleton of a human body. CSS adds beauty, and JavaScript adds movement.

Basic HTML Structure

<!DOCTYPE html> <html> <head> <title>My First Page</title> </head> <body> <h1>Hello World</h1> <p>My first webpage.</p> </body> </html>

Important HTML Tags

Tag Purpose
<h1> Main Heading
<p> Paragraph
<a> Hyperlink
<img> Image
<ul> Unordered List

Example

<h1>Welcome</h1> <p>I am learning HTML.</p>

Output


Welcome

I am learning HTML.
