CSS Basics

Learn how to style your webpages.

What is CSS?

CSS stands for Cascading Style Sheets. It controls the appearance of a webpage.


HTML builds the structure, while CSS makes it beautiful.

CSS Syntax

h1{ color: blue; font-size: 40px; }

Here:

  • h1 → Selector
  • color → Property
  • blue → Value

Common CSS Properties

Property Purpose
color Changes text color
background Background color
font-size Changes text size
border Adds border

Example

<style> h1{ color:red; } </style> <h1> Hello CSS </h1>
